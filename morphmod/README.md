# Morph Mod (Fabric 1.21.11, Mojang mappings, singleplayer MVP)

Controls: kill a mob -> its morph is unlocked. Press M to open the menu.
Unlocked morphs are stored in config/morphmod.json.

Build: ./gradlew build (JDK 21) or push to GitHub, jar appears in Actions > Artifacts
Jar:    build/libs/morphmod-0.1.0.jar
