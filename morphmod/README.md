# Morph Mod (Fabric 1.21.11, Mojang mappings, singleplayer)

Kill a mob -> its essence flows into you -> the morph is acquired.
Selector (HUD): [ and ] to move, Enter to confirm, Backspace to cancel (rebind in Controls).
First entry of the list = human (demorph). Morphs are stored in config/morphmod.json.

The look and behaviour of the selector and the acquisition effect are inspired by iChun's Morph mod
(LGPL-3.0); no code or assets were copied.
